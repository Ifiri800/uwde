# Universal Web Data Extractor (UWDE)

Universal Web Data Extractor is a web-based application that allows users to enter a website URL, describe the information they want to collect, and extract structured data from websites.

## Project Goals

UWDE is designed to support:

- Static HTML websites
- JavaScript-rendered websites
- Browser automation
- Point-and-click extraction
- Natural-language extraction instructions
- Pagination and crawling
- Data cleaning and normalization
- Dataset previews
- CSV, JSON and Excel exports
- Reusable scraping recipes
- Scheduled extractions
- Authentication and authorization
- Security controls
- Automated testing
- Production deployment

## Project Structure

- `frontend/` — User interface
- `backend/` — API and application services
- `scraper/` — Web scraping services
- `browser/` — Browser automation
- `extraction/` — Data extraction engine
- `crawling/` — Pagination and crawling
- `processing/` — Data processing and validation
- `database/` — Database layer
- `tests/` — Automated tests
- `docs/` — Documentation
